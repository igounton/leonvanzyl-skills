# Sample slides

Five 1920×1080 slides built only from this system's components, one per core layout. Click, or use the arrow keys and space, to move between them.

1. **Hero with code:** `SlideTitle size="display"` with two icon tiles, beside a `CodePanel` with the cursor.
2. **Comparison:** `SlideTitle`, then two `GlassPanel`s. The winner is highlighted, with an accent `Stat` and a fast `Track`.
3. **Split with a product window:** `SlideTitle size="split"` with a tile after the first word, a `ProductWindow` of answers with `Pill`s, and a `TaskCard` overlapping its lower-left edge. The window leaves empty room at the bottom for the card. Ember accent.
4. **Table:** `SlideTitle`, then a `DataTable` in a `GlassPanel`, with the source line inside the panel and a quieter wave.
5. **Big stat:** a `Stat` at 220px beside a `GlassPanel` of `BarRow`s.

Every slide keeps the right-hand 380px webcam lane empty and all bare-stage text above the wave. The content is from the Jev explainer (TypeSafe's published figures, list prices September 2026).
